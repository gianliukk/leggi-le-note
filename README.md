# Leggi le note

Percorso a tappe per imparare a leggere la musica: note in chiave di violino, valori delle figure e delle pause. Lo guida il prof. Marano, un gufo musicista con il clarinetto.

Sito: https://gianliukk.github.io/leggi-le-note/

## Struttura

- `index.html`: la pagina
- `css/stile.css`: grafica
- `js/dati.js`: livelli e unità del percorso
- `js/progressi.js`: stelle, XP e serie giornaliera
- `js/pentagramma.js`: disegno del pentagramma
- `js/gufo.js`: il prof. Marano e le sue espressioni
- `js/lezioni.js`: le lezioni di teoria
- `js/suono.js`: suoni di clarinetto
- `js/app.js`: navigazione, tappe ed esito
- `audio/clarinetto.json`: campioni di clarinetto
